Privacy

This site is static files on GitHub Pages behind Cloudflare. It sets no cookies and keeps no accounts. Page views are counted by a self-hosted, cookieless Umami instance operated by 48Nauts (wave.21nauts.com); it records the page, referrer, browser family and country, no personal identifiers, and honours Do Not Track. The data published here was collected from public GitHub repositories and describes files, not people; repository owners are named because the files are theirs. To request a recheck or a correction, open an issue on the whichskills repository.

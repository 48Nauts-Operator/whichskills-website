Privacy

This site is static files on GitHub Pages behind Cloudflare. It sets no cookies and keeps no accounts. If analytics are enabled they run on a self-hosted, cookieless Umami instance operated by 48Nauts and record page views without personal identifiers. The data published here was collected from public GitHub repositories and describes files, not people; repository owners are named because the files are theirs. To request a recheck or a correction, open an issue on the whichskills repository.
